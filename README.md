\# DA-04: Finance Analytics \& Credit Risk



\## Project Overview

This project demonstrates an end-to-end Finance Analytics and Credit Risk solution for Nexvia Technologies. It combines financial reporting, loan risk analysis, SQL-based data analysis, dashboards, and report automation.



\## Project Objectives

\- Analyse monthly financial performance.

\- Compare actual results against budget.

\- Reconcile balance sheet figures.

\- Analyse loan and borrower risk.

\- Build a logistic regression credit risk model.

\- Create interactive Excel and Power BI dashboards.

\- Automate monthly finance report generation.



\## Tools \& Technologies

\- \*\*Python:\*\* pandas, NumPy, scikit-learn, Matplotlib, seaborn

\- \*\*SQL:\*\* MySQL

\- \*\*Excel:\*\* Excel and Power Pivot

\- \*\*Power BI:\*\* Finance and Credit Risk dashboards

\- \*\*Power Automate Desktop:\*\* Monthly report automation

\- \*\*VS Code:\*\* Python development environment



\## Data Sources

1\. \*\*Synthetic Finance Data:\*\* Fictional financial transactions, accounts, budgets, balance sheets, and monthly business drivers generated for this project.

2\. \*\*Lending Club Dataset:\*\* \[Kaggle – Lending Club Loan Data](https://www.kaggle.com/datasets/wordsforthewise/lending-club)



The project uses a cleaned Lending Club dataset for credit risk analysis. Raw source files are kept separate from processed data and outputs.



\## Project Structure

\- Monthly finance PDF generation was successfully tested.



\## Limitations

\- Synthetic finance data is used for demonstration and does not represent actual company financial records.

\- Credit risk model performance depends on the available historical Lending Club data and selected features.

\- Model predictions are analytical outputs and should not be treated as actual lending decisions.

\- Some historical scorecard outputs are separate from the current logistic regression workflow.
